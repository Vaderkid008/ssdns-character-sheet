# Oscar Slots — Rock Machines (Whiskey Bend)

## Play

1. **Set** / **Add** Eldorite chips.
2. Pick bet: **1× 2× 5× 10× 20× 50× 75×** or **ALL IN** (entire stack).
3. Ante = `5 × multiplier` (or full balance on All In).
4. **SPIN**.

## Symbols

- Eldorite crystals: Clear 1 · Amber 5 · Blue 20 · Green 50 · Violet 100 · Crimson 500
- **Outlaw WILD** — gunmetal badge (wild for any crystal). Triple WILD = 25× saloon jackpot.

## Volatility (mild)

Higher bets slightly reduce wild / top-crystal weight and bump common stones:

| Bet | Feel |
|-----|------|
| 1×–2× | Standard |
| 5×–10× | A little leaner |
| 20×+ / All In | High-stakes (still fair, not punitive) |

## Payouts

| Result | Pay |
|--------|-----|
| 2 matching crystals (wilds count) | 2× ante |
| 3 matching crystals | 10× ante |
| Triple Crimson | 10× + banner |
| 2 WILD | 5× ante if best |
| 3 WILD | 25× ante + jackpot |

## SFX

Chip clinks, bet blips, All In rumble, cylinder, **layered gunshots** on wins (heavier on triples/jackpots), ricochets, whistle.
